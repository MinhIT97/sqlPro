# Quy ước phát triển SqlPro

Tài liệu này mô tả kiến trúc đang dùng và quy tắc cho thay đổi mới. Phạm vi gồm website giới thiệu, ứng dụng Electron và server đồng bộ. Không áp dụng một pattern chỉ để có tên pattern; ưu tiên ranh giới rõ, mã dễ kiểm thử và hành vi hiện có.

## Cấu trúc và design pattern đang áp dụng

| Phần | Pattern / cách tổ chức | Quy tắc sử dụng |
| --- | --- | --- |
| `website/` | Module khởi tạo bằng IIFE và các hàm `init...` độc lập | Mỗi hành vi DOM có hàm khởi tạo riêng; trạng thái ngắn hạn nằm trong closure. `core.js` giữ logic thuần cho bộ cài, checksum, tìm kiếm và cấu hình tự host; `app.js` điều phối API/DOM. HTML song ngữ được sinh từ template chung trong `scripts/build-website.cjs` và nội dung `scripts/website-docs.cjs`, vẫn dùng được khi không có JavaScript. |
| `website/styles.css` | Design tokens và CSS theo component | Màu, font, bán kính, bóng dùng biến ở `:root`; style nằm trong nhóm component tương ứng; responsive ở các breakpoint hiện có. |
| `electron/main.cjs` + `electron/preload.cjs` + `app.js` | Phân lớp main / preload facade / renderer | Main sở hữu hệ điều hành, tệp, secret và database; preload chỉ công bố API IPC có tên rõ; renderer chỉ giữ trạng thái và vẽ UI. |
| `electron/database.cjs` | Session object cho kết nối database | `DatabaseSession` giữ vòng đời kết nối, timeout và hủy; thao tác SQL đi qua session thay vì kết nối trực tiếp từ renderer. |
| `electron/session-registry.cjs` | Resource registry, single-flight và lease | Factory tạo phiên được inject; gộp mở cùng profile, admission tuần tự, bảo vệ phiên bận/transaction và vô hiệu hóa kết quả mở cũ bằng generation. Explicit disconnect được phép đóng phiên; LRU chỉ đóng phiên rảnh. |
| `electron/table-data.cjs` | Application service và chính sách phân trang | Tách SQL plan/count cache khỏi IPC. Dùng keyset khi thứ tự PK cho phép, OFFSET làm fallback; COUNT chỉ theo yêu cầu và cache có TTL/invalidation. |
| `electron/table-search.cjs` | Predicate tìm kiếm thuần dùng chung | Grid/count/export dùng cùng builder, quote tên từ metadata và bind values. Chứa/prefix escape `=`, `%`, `_` với ESCAPE '='; prefix một cột text dùng LIKE trực tiếp, kiểu khác/all dùng CAST, không hứa index. Exact một cột dùng coerce hiện có; NULL/NOT NULL bắt buộc một cột và bỏ giá trị nhập. Mode/cột sai phải báo lỗi, không fallback toàn bảng. Count/cursor key gắn term/cột/mode; không thêm COUNT tự động hoặc policy ghi. |
| `table-filters.js` + hộp thoại trong `app.js` | Cây điều kiện versioned và compiler thuần dùng chung | Root v1 AND/OR, nested group có giới hạn; renderer preview và main compile lại trên metadata thực. Không raw SQL; tên quote, giá trị bind, key canonical và tree frozen. Ghép AND với tìm nhanh, grid/count/export giữ cùng predicate; main forward filterTree tường minh khi export. Asset cập nhật index/packaging/check/test helper. |
| `table-view.js` + `electron/table-data.cjs` | Order plan thuần, visibility trình bày | Sorts tối đa 5 entry own column/direction ASC/DESC, exact metadata names, không trùng/unknown/sparse; main validate lại. Append PK còn thiếu theo hướng sort đầu/default ASC. Keyset chỉ khi requested đều PK; lexicographic dùng hướng riêng mỗi key, reverse lật từng hướng. Non-PK dùng OFFSET; signature gắn effective entries, COUNT không gắn sort. Visibility chỉ lọc metadata render, không cắt row/PK/original snapshot; export có opt-in projection riêng và cùng order plan. |
| `electron/result-budget.cjs` + `query-results.js` | Value object và logic trình bày thuần | Giới hạn row/byte SQL result; giữ origIndex trước sort, không tìm index từng dòng. Query bị giới hạn dùng control connection gửi KILL QUERY; không phá phiên SQL chỉ để cắt kết quả hiển thị. |
| `query-snippets.js` + modal Snippets & Lịch sử trong `app.js` | Module thuần UMD quản lý mẫu SQL và lịch sử có che giấu dữ liệu nhạy cảm | Chuẩn hóa, tìm kiếm đa trường và dọn dẹp lịch sử theo giới hạn count/thời gian. Hàm `scrubSensitiveSql` che giấu mật khẩu, token và khóa bí mật trước khi lưu hoặc hiển thị. Chèn snippet vào editor tại vị trí con trỏ và bảo toàn ngăn xếp undo/redo qua `recordSqlEditorChange`. |
| `diagnostics.js` + modal Dashboard chẩn đoán trong `app.js` | Module thuần UMD cho chẩn đoán server, tiến trình, khóa & giao dịch | Chuẩn hóa dòng processlist, định dạng thời lượng, nhận diện thread hệ thống và kết nối hiện tại. Tự động rẽ nhánh truy vấn khóa giữa MySQL 8.0+ (`performance_schema.data_lock_waits`) và MySQL 5.7 / MariaDB (`information_schema.innodb_lock_waits`). Tạo câu lệnh `KILL QUERY` an toàn thay vì hủy toàn bộ kết nối nếu không cần thiết; cảnh báo tường minh khi can thiệp vào thread hệ thống hoặc phiên của chính mình. |
| `schema-diff.js` + modal Schema Diff trong `app.js` | Module thuần UMD so sánh cấu trúc lược đồ CSDL và sinh mã migration DDL | Chuẩn hóa snapshot schema, so sánh sâu cấu trúc giữa 2 CSDL (bảng, cột, chỉ mục, khóa ngoại, views, routines). Phân loại rủi ro (an toàn, cảnh báo, nguy hiểm) và sắp xếp trật tự phụ thuộc DDL (topological execution ordering). Cung cấp cơ chế chặn phá hủy an toàn (vô hiệu hóa lệnh DROP mặc định), hỗ trợ mở trong SQL Editor và áp dụng trực tiếp. |
| `data-masking.js` + toggle che giấu PII trong `app.js` | Module thuần UMD che giấu dữ liệu nhạy cảm thông minh (Smart Data Masking) | Thuật toán che giấu bảo toàn định dạng (email, số điện thoại, thẻ tín dụng, mật khẩu/token, CCCD/CMND/hộ chiếu). Heuristic nhận diện nhạy cảm tự động song ngữ Anh-Việt. Tích hợp tầng hiển thị không phá hủy (giữ nguyên dữ liệu gốc `app.rows`/`result.rows` cho sửa ô an toàn) và bảo vệ dữ liệu khi xuất (CSV/JSON/SQL). Lưu trạng thái vào `localStorage`. |
| `audit-log.js` + `electron/audit-log.cjs` + modal trong `app.js` | Module thuần UMD và store nguyên tử ghi nhật ký thao tác cục bộ (Local Audit Log) | Phân loại câu lệnh SQL tự động (`QUERY`, `INSERT`, `UPDATE`, `DELETE`, `DDL`, `BACKUP`, `RESTORE`, `EXPORT`, `IMPORT`, `KILL`, `SCHEMA_DIFF`). Tự động làm sạch mật khẩu và token nhạy cảm (`sanitizeAuditSummary`). Không lưu dữ liệu dòng hay secret. Lưu trữ nguyên tử `.part` an toàn trong Electron, giới hạn quota 2 MB / 1.000 bản ghi, bảo toàn file khi có lỗi. Hỗ trợ lọc đa điều kiện, dọn dẹp theo thời gian, xuất RFC-4180 CSV / JSON kèm điều khoản miễn trừ trách nhiệm. |
| `data-diff.js` + modal Data Diff trong `app.js` | Module thuần UMD so sánh và đồng bộ dữ liệu bảng (Table Data Diff & Synchronization) | So sánh canonical giá trị (phân biệt `NULL` vs chuỗi rỗng `""`, boolean, decimal, datetime, JSON). Trích xuất khóa chính composite, phân loại bản ghi (`identical`, `different`, `onlyInSource`, `onlyInTarget`), sinh mã đồng bộ an toàn (INSERT, UPDATE, và DELETE có khóa an toàn). Tích hợp highlight trực quan, che giấu dữ liệu PII và ghi nhận nhật ký audit. |
| Phần EXPLAIN trong `query-results.js` + `app.js` | Diễn giải kết quả thuần và trình bày có giới hạn | Chỉ đọc result isExplain/dạng bảng với column names không trùng; không suy DESCRIBE/JSON/tree là plan truyền thống. Đọc 200 dòng/hiện 50, số sai/không an toàn phải unknown; giữ ước lượng từng dòng, không cộng JOIN hoặc suy tốc độ từ kiểu truy cập. ALL/index/filesort/temporary là tín hiệu, không tự khuyên thêm index; không thêm query/ANALYZE hay sửa kết quả gốc. Escape identifier, details hỗ trợ bàn phím và cuộn riêng trong cửa sổ nhỏ. |
| JSON/TREE EXPLAIN trong `query-results.js` + `app.js` | Xem văn bản server có quota, định dạng theo lựa chọn tường minh | Chọn DEFAULT/JSON/TREE trong bộ nhớ từng tab; không version-guess/probe/fallback, lỗi server phải hiển thị, SQL đã có EXPLAIN/DESC giữ nguyên. Nút EXPLAIN chặn ANALYZE/executable comments/hints; không thay policy main. Capture SQL/selection trước await, đối chiếu tab/busy sau await và giữ database trả về trong target. Viewer chỉ nhận một cell EXPLAIN string, JSON validate rồi indent tokens không reserialize số/key; không normalize semantics hai engine. Quota 262.144 UTF-16 chars, depth 64, 10.000 tokens, output 524.288 chars; thiếu/sai/quota trả raw/cảnh báo. Escape tất cả text, không tự lưu plan/query literals vào workspace/log, không tự thực thi hoặc xác nhận an toàn. |
| So sánh EXPLAIN trong `main.cjs` + `query-results.js` + `app.js` | Observation do main sở hữu và một mốc tạm theo tab | Main chỉ thêm explainContext v1 sau EXPLAIN rows hoàn tất khi entry/profile còn khớp; dùng session UUID, database thực tế, SHA-256 SQL, taskId và thời gian, không renderer-provided identity/SQL/secret hoặc quyền chạy. Mặc định không query thêm; tùy chọn thiết lập tuân theo quy tắc bên dưới. Context thiếu/stale giữ null và bảo toàn kết quả. capture kiểm tra binding/profile/database/task/quota/shape, freeze evidence và row projection; compare theo exact scope/order/cell, không normalize JOIN/JSON hoặc suy tốc độ/schema/settings/data. WeakMap giữ lần thành công liền trước, tối đa 200 dòng/64 cột/evidence 262.144 chars; hiện 50 diff/Extra 4.096 chars/native text có quota. Lỗi/hủy/normal SQL/close/reset/logout xóa mốc, generation chặn quan sát muộn sau invalidation; không lưu plan/scope ra đĩa. |
| `server/src/async-gate.cjs` | Semaphore với hàng đợi hữu hạn | Scrypt chạy bất đồng bộ, giữ nguyên KDF; giới hạn công việc đồng thời/hàng đợi, trả AUTH_BUSY khi đầy. Không giảm độ khó hash để tăng tốc. |
| `electron/store.cjs` + `electron/store-schema.cjs` | Repository và normalization boundary | Đọc/ghi profile và workspace qua store; chuẩn hóa dữ liệu ở đầu vào, tách secret khỏi dữ liệu trả về renderer. |
| `electron/backup-annotations.cjs` + `electron/backup-catalog.cjs` | Metadata repository và khóa theo tệp | Tên/ghi chú/ghim đọc tương thích sidecar cũ, ghi atomic và tuần tự hóa edit/delete. Xóa kiểm tra pin tại catalog service; metadata hỏng phải báo lỗi và giữ nguyên. Copy giữ metadata trước khi công bố SQL. |
| `electron/backup-retention-apply.cjs` | Kế hoạch bất biến, token một lần và kiểm tra drift | Preview do main đọc catalog, TTL hữu hạn và scope profile/database. Apply phải xác nhận native, kiểm tra lại toàn catalog và hash bản giữ, dùng chung khóa annotation cho copy/verify/export/delete. Báo phần đã xóa, dừng khi lỗi; không suy preview là quyền xóa lâu dài. |
| `electron/backup-retention-auto.cjs` | Tác vụ theo sau backup với opt-in lưu cục bộ | Bật/chỉnh chính sách tự dọn cần xác nhận native; chỉ chạy sau backup mới đã ghi thành công. Bắt buộc bản mới là anchor, cùng source target identity và scope metadata; inventory phải khớp counts, bản cũ thiếu target được giữ. Lỗi dọn không được đổi kết quả backup thành thất bại. Giữ transfer slot/cancel, generation khi logout/đóng cửa sổ, kiểm tra policy/profile drift và báo cáo phần đã xóa. |
| `electron/backup-file.cjs` | Công bố tệp hoàn chỉnh và manifest theo lựa chọn ghi | Backup catalog phải dùng `exclusive: true`, công bố bằng hard link không thay SQL/manifest đã có. Gỡ tên tạm trước khi chụp file identity. Export do người dùng chọn giữ hành vi ghi thay hiện có. Đọc manifest giới hạn 2 MiB, từ chối symlink; version 1 cũ vẫn đọc, thiếu target không đủ điều kiện tự dọn. |
| `electron/backup-scheduler.cjs` | Repository local và bộ chạy interval có claim trước tác vụ | Một lịch/profile/database, tối đa 50, chu kỳ 1–168 giờ trôi qua. Ghi claim và kỳ tiếp trước khi mở phiên backup riêng; restart đánh dấu incomplete, không phát lại. Quá grace thì missed/busy, không catch-up/retry. Dùng generation cho stop/restart và đọc lại lịch sau await; lỗi ghi kết quả dừng bộ chạy, không suy backup đã thất bại. Main xác nhận native khi lưu, kiểm tra target identity và hủy khi logout/đóng cửa sổ; renderer chỉ dùng API có tên. |
| `electron/restore-selection.cjs` | Collector và preview nguồn thuần, chưa phải execution plan | Chỉ bật collector qua option worker khi đọc backup; restore hiện tại mặc định tắt. Giữ tên exact bằng tokenizer phân biệt keyword/identifier/string/comment, quota table/edge/definition/findings hữu hạn. FK chỉ từ CREATE TABLE, phần chưa phân tích phải báo giới hạn. Preview luôn `canExecute:false`, không query đích, không cấp token chạy, không đổi lựa chọn restore toàn bộ. Không dùng cache display để cho phép ghi. |
| `electron/restore-selection-expressions.cjs` | Quan sát DEFAULT/generated và phát hiện drift metadata thuần | Mở rộng SELECT COLUMNS sẵn có bằng SHA2 tại server cho DEFAULT 0–64 KiB/generated 1–64 KiB; không raw value/expression. Profile v1 giữ status/digest nội bộ, missing/cũ/sai/hasDefault-generated flags không nhất quán phải unknown; DEFAULT metadata NULL không chứng minh absence. Review schema/table/case/duplicate/metadata/quota; identity cột trùng phải đưa mọi quan sát trùng về unknown, 10.000 cột/report 200/UI 100. Report v1/plan chỉ whitelist identifiers/status, không digest riêng. Snapshot v16/metadataId binding v2/plan v29 gắn thay đổi giữa hai giá trị non-null hoặc cùng tên generated; bind/freeze report giữ default/generated/recheck gates và canExecute:false. Không đánh giá biểu thức, nguồn/đích hay nới CREATE/full restore/trial/backup format, không thêm SELECT/executor/token/apply. |
| `restore-review.js` + phần so sánh trong `app.js` | Quan sát tạm renderer và hàm so sánh thuần | Chỉ capture kết quả main canExecute:false có digest/version/time và binding checksum/snapshot/schema/selection/policy đúng request. Scope JSON tuple exact có table sort, không SQL/body/secret; một mốc bất biến trong closure hộp thoại, xóa khi thay selection/target/policy/source-only/lỗi/hủy/đóng, stale generation không cập nhật. So checksum, metadataId tổng hợp (snapshot v16) và planId v28; khác schema version/scope/thiếu/mâu thuẫn phải unknown/mốc mới, không kết luận safe. MetadataId không gắn bytes/flags/time nguồn; không bằng chứng dữ liệu dòng không đổi, không authority/token/registry/apply, không lưu localStorage/sidecar. Cập nhật index và packaging allowlist cùng module; smoke từ app.asar qua SQLPRO_RENDERER_APP_ROOT. |
| `electron/restore-selection-triggers.cjs` | Collector và report trigger đích có quota, chưa chứng nhận side effects | Mở rộng SELECT TRIGGERS sẵn có với timing/orientation/order và SHA2 body ≤64 KiB/context ≤32 KiB tại server. Context hash cố định SQL_MODE/DEFINER/charset/collations; không raw body/account/mode. Normalize whitelist, metadata v1; schema/table/case/duplicate/quota/missing/legacy/denied phải unknown. Digest chỉ ở facts nội bộ/snapshot v16, không renderer/report/plan; project trả boolean quan sát/tên/event/timing/order. Report v1 200 rows, UI 100, collector 5.000; không suy absence từ rỗng. Projection đối chiếu tổng INSERT với events đã giữ và quota rows chưa giữ. Plan v29 bind/freeze report và giữ side-effect/visibility/recheck gates/canExecute:false; không phân tích body hoặc mở executor, không đổi full restore/trial/backup format. |
| `electron/restore-selection-engines.cjs` | Quan sát engine đích và gate bản nháp thuần | Đọc ENGINE trong SELECT TABLES sẵn có, không tăng tối đa 12 SELECT; normalize tên ASCII đầy đủ ≤64 ký tự, thiếu/sai/view thành null. Chỉ nhận một table identity khớp theo case policy và metadata đủ; engine chưa rõ/ngoài InnoDB chặn INSERT data-only trong plan v29 sau schema/skip/policy guards. Plan dựng lại từ objects, không tin engineReview có sẵn, bind/freeze report v1; snapshot v16 bind metadata. Catalog complete không có nghĩa engine đã được xác minh. InnoDB không chứng nhận rollback DDL/trigger/ghi gián tiếp; giữ recheck/indirect gates và canExecute:false. UI 100 bảng, không lộ giá trị/SQL; không đổi full restore/trial hoặc format backup. |
| `electron/restore-selection-target.cjs` | Đọc metadata đích và báo cáo đối chiếu có digest | Chỉ SELECT metadata với schema parameter binding, timeout/quota và lỗi chưa xác định. Phiên riêng cùng transfer slot, fresh hash nguồn và kiểm tra identity/profile/generation sau await; AbortSignal phải tới scanner kể cả khi chưa qua stat. Digest gắn nguồn/selection/target/metadata, không phải quyền chạy hay snapshot DB nguyên tử. Báo cáo luôn partial/canExecute:false; metadata trống không chứng minh đích không có đối tượng. |
| `electron/restore-selection-columns.cjs` | Phân tích metadata cột và đối chiếu thuần | Đọc cột CREATE và tên cột INSERT với quota; không giữ SQL literal/default/generated expression/nhãn enum. Kiểu hoặc thuộc tính chưa hỗ trợ phải báo chưa xác định. So thuộc tính và thứ tự INSERT theo vị trí, không suy tương thích giá trị hay quyền phục hồi. Digest kiểu đích giữ khác biệt hoa/thường của kiểu chưa hỗ trợ; báo cáo luôn partial, không cấp quyền ghi. |
| `electron/restore-selection-plan.cjs` | Bản nháp review bất biến với danh sách câu lệnh có giới hạn | Main dựng từ inventory/source/target đọc mới, gắn checksum, selection, đích và snapshot metadata; deep-freeze trước IPC. Luôn blocked/canExecute:false, không có token/registry/apply. Candidate chỉ là câu được gán vào lựa chọn, chưa chứng minh cú pháp/tác động. DROP, context và câu chưa phân loại phải có lý do chặn; thiếu/quá quota/gãy số thứ tự không được coi là đầy đủ. Chỉ lưu metadata, không SQL text/literal; bản sao IPC không là quyền thực thi. |
| `electron/restore-selection-syntax.cjs` | Bộ nhận diện cú pháp INSERT literal thuần, có quota | Chỉ nhận toàn câu INSERT INTO/VALUES theo grammar hữu hạn; không dùng SQL đã scrub để suy literal. Không giữ/trả giá trị, từ chối escape/quote/comment chưa hỗ trợ, hàm/biểu thức và phần nối sau VALUES.
