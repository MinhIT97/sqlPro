# Quy ước phát triển SqlPro

Tài liệu này mô tả kiến trúc đang dùng và quy tắc cho thay đổi mới. Phạm vi gồm website giới thiệu, ứng dụng Electron và server đồng bộ. Không áp dụng một pattern chỉ để có tên pattern; ưu tiên ranh giới rõ, mã dễ kiểm thử và hành vi hiện có.

## Cấu trúc và design pattern đang áp dụng

| Phần | Pattern / cách tổ chức | Quy tắc sử dụng |
| --- | --- | --- |
| `website/` | Module khởi tạo bằng IIFE và các hàm `init...` độc lập | Mỗi hành vi DOM có hàm khởi tạo riêng; trạng thái ngắn hạn nằm trong closure. `core.js` giữ logic thuần cho bộ cài, checksum, tìm kiếm và cấu hình tự host; `app.js` điều phối API/DOM. HTML song ngữ được sinh từ template chung trong `scripts/build-website.cjs` và nội dung `scripts/website-docs.cjs`, vẫn dùng được khi không có JavaScript. |
| `website/styles.css` | Design tokens và CSS theo component | Màu, font, bán kính, bóng dùng biến ở `:root`; style nằm trong nhóm component tương ứng; responsive ở các breakpoint hiện có. |
| `electron/main.cjs` + `electron/preload.cjs` + `app.js` | Phân lớp main / preload facade / renderer | Main sở hữu hệ điều hành, tệp, secret và database; preload chỉ công bố API IPC có tên rõ; renderer chỉ giữ trạng thái và vẽ UI. |
| `electron/database.cjs` | Session object cho kết nối database | `DatabaseSession` giữ vòng đời kết nối, timeout và hủy; thao tác SQL đi qua session thay vì kết nối trực tiếp từ renderer. |
| `electron/session-registry.cjs` | Resource registry, single-flight và lease | Factory tạo phiên được inject; gộp mở cùng profile, admission tuần tự, bảo vệ phiên bận/transaction và vô hiệu hóa kết quả mở cũ bằng generation. Explicit disconnect được phép đóng phiên; LRU chỉ đóng phiên rảnh. |
| `electron/table-data.cjs` | Application service và chính sách phân trang | Tách SQL plan/count cache khỏi IPC. Dùng keyset khi thứ tự PK cho phép, OFFSET làm fallback; COUNT chỉ theo yêu cầu và cache có TTL/invalidation. |
| `electron/result-budget.cjs` + `query-results.js` | Value object và logic trình bày thuần | Giới hạn row/byte SQL result; giữ origIndex trước sort, không tìm index từng dòng. Query bị giới hạn dùng control connection gửi KILL QUERY; không phá phiên SQL chỉ để cắt kết quả hiển thị. |
| `server/src/async-gate.cjs` | Semaphore với hàng đợi hữu hạn | Scrypt chạy bất đồng bộ, giữ nguyên KDF; giới hạn công việc đồng thời/hàng đợi, trả AUTH_BUSY khi đầy. Không giảm độ khó hash để tăng tốc. |
| `electron/store.cjs` + `electron/store-schema.cjs` | Repository và normalization boundary | Đọc/ghi profile và workspace qua store; chuẩn hóa dữ liệu ở đầu vào, tách secret khỏi dữ liệu trả về renderer. |
| `electron/backup-annotations.cjs` + `electron/backup-catalog.cjs` | Metadata repository và khóa theo tệp | Tên/ghi chú/ghim đọc tương thích sidecar cũ, ghi atomic và tuần tự hóa edit/delete. Xóa kiểm tra pin tại catalog service; metadata hỏng phải báo lỗi và giữ nguyên. Copy giữ metadata trước khi công bố SQL. |
| `electron/backup-retention-apply.cjs` | Kế hoạch bất biến, token một lần và kiểm tra drift | Preview do main đọc catalog, TTL hữu hạn và scope profile/database. Apply phải xác nhận native, kiểm tra lại toàn catalog và hash bản giữ, dùng chung khóa annotation cho copy/verify/export/delete. Báo phần đã xóa, dừng khi lỗi; không suy preview là quyền xóa lâu dài. |
| `electron/backup-retention-auto.cjs` | Tác vụ theo sau backup với opt-in lưu cục bộ | Bật/chỉnh chính sách tự dọn cần xác nhận native; chỉ chạy sau backup mới đã ghi thành công. Bắt buộc bản mới là anchor, cùng source target identity và scope metadata; inventory phải khớp counts, bản cũ thiếu target được giữ. Lỗi dọn không được đổi kết quả backup thành thất bại. Giữ transfer slot/cancel, generation khi logout/đóng cửa sổ, kiểm tra policy/profile drift và báo cáo phần đã xóa. |
| `electron/backup-file.cjs` | Công bố tệp hoàn chỉnh và manifest theo lựa chọn ghi | Backup catalog phải dùng `exclusive: true`, công bố bằng hard link không thay SQL/manifest đã có. Gỡ tên tạm trước khi chụp file identity. Export do người dùng chọn giữ hành vi ghi thay hiện có. Đọc manifest giới hạn 2 MiB, từ chối symlink; version 1 cũ vẫn đọc, thiếu target không đủ điều kiện tự dọn. |
| `electron/backup-scheduler.cjs` | Repository local và bộ chạy interval có claim trước tác vụ | Một lịch/profile/database, tối đa 50, chu kỳ 1–168 giờ trôi qua. Ghi claim và kỳ tiếp trước khi mở phiên backup riêng; restart đánh dấu incomplete, không phát lại. Quá grace thì missed/busy, không catch-up/retry. Dùng generation cho stop/restart và đọc lại lịch sau await; lỗi ghi kết quả dừng bộ chạy, không suy backup đã thất bại. Main xác nhận native khi lưu, kiểm tra target identity và hủy khi logout/đóng cửa sổ; renderer chỉ dùng API có tên. |
| `electron/restore-selection.cjs` | Collector và preview nguồn thuần, chưa phải execution plan | Chỉ bật collector qua option worker khi đọc backup; restore hiện tại mặc định tắt. Giữ tên exact bằng tokenizer phân biệt keyword/identifier/string/comment, quota table/edge/definition/findings hữu hạn. FK chỉ từ CREATE TABLE, phần chưa phân tích phải báo giới hạn. Preview luôn `canExecute:false`, không query đích, không cấp token chạy, không đổi lựa chọn restore toàn bộ. Không dùng cache display để cho phép ghi. |
| `electron/restore-selection-target.cjs` | Đọc metadata đích và báo cáo đối chiếu có digest | Chỉ SELECT metadata với schema parameter binding, timeout/quota và lỗi chưa xác định. Phiên riêng cùng transfer slot, fresh hash nguồn và kiểm tra identity/profile/generation sau await; AbortSignal phải tới scanner kể cả khi chưa qua stat. Digest gắn nguồn/selection/target/metadata, không phải quyền chạy hay snapshot DB nguyên tử. Báo cáo luôn partial/canExecute:false; metadata trống không chứng minh đích không có đối tượng. |
| `electron/restore-selection-columns.cjs` | Phân tích metadata cột và đối chiếu thuần | Đọc cột CREATE và tên cột INSERT với quota; không giữ SQL literal/default/generated expression/nhãn enum. Kiểu hoặc thuộc tính chưa hỗ trợ phải báo chưa xác định. So thuộc tính và thứ tự INSERT theo vị trí, không suy tương thích giá trị hay quyền phục hồi. Digest kiểu đích giữ khác biệt hoa/thường của kiểu chưa hỗ trợ; báo cáo luôn partial, không cấp quyền ghi. |
| `electron/restore-selection-plan.cjs` | Bản nháp review bất biến với danh sách câu lệnh có giới hạn | Main dựng từ inventory/source/target đọc mới, gắn checksum, selection, đích và snapshot metadata; deep-freeze trước IPC. Luôn blocked/canExecute:false, không có token/registry/apply. Candidate chỉ là câu được gán vào lựa chọn, chưa chứng minh cú pháp/tác động. DROP, context và câu chưa phân loại phải có lý do chặn; thiếu/quá quota/gãy số thứ tự không được coi là đầy đủ. Chỉ lưu metadata, không SQL text/literal; bản sao IPC không là quyền thực thi. |
| `electron/restore-selection-syntax.cjs` | Bộ nhận diện cú pháp INSERT literal thuần, có quota | Chỉ nhận toàn câu INSERT INTO/VALUES theo grammar hữu hạn; không dùng SQL đã scrub để suy literal. Không giữ/trả giá trị, từ chối escape/quote/comment chưa hỗ trợ, hàm/biểu thức và phần nối sau VALUES. Collector giới hạn bytes toàn inventory và chỉ bật cho preview; plan kiểm tra tên/shape bằng chứng, chiếu field an toàn và bind version. Matched chỉ là cú pháp, không chứng minh tương thích giá trị/side effects hoặc đủ điều kiện ghi. Không tái sử dụng làm quyền chạy. |
| `electron/restore-selection-create.cjs` | Bộ nhận diện grammar CREATE TABLE cơ bản, chỉ đọc | Phân tích toàn câu SQL gốc với tên backtick và ENGINE=InnoDB, kiểu/thuộc tính/index/options/FK hữu hạn. Bằng chứng v3 giữ định nghĩa index và cặp cột/action FK, không literal/default/comment; generated/CHECK chưa hỗ trợ. Chia sẻ 32 MiB syntax budget với INSERT/context, thêm quota 64 FK/câu, 16 cặp/FK, 2.000 FK/10.000 cặp và 5.000 index/20.000 index parts toàn inventory. Plan v16 đối chiếu target/shape bằng chứng, chiếu whitelist và chặn review v1/v2 cũ; matched không chứng minh semantic compatibility hay quyền thực thi. Không dùng để nới preflight restore toàn bộ/trial. |
| `electron/restore-selection-context.cjs` | Nhận diện mẫu SET và đối chiếu trình tự dump thuần | Chỉ 5 mẫu SET native từ SQL gốc, tối đa 16 KiB/câu; không giữ RHS/literal/SQL. Project bằng whitelist action/code, xem toàn ledger kể cả bảng ngoài lựa chọn, báo missing/duplicate/order/quota và review cũ. Kết quả luôn canExecute:false; SET khớp vẫn blocked, cần chính sách phiên riêng, cleanup, SQL_MODE review và FK recheck. Không coi bật FK lại là kiểm chứng dữ liệu; không sửa validator của restore toàn bộ/trial. |
| `electron/restore-selection-decimal.cjs` | Thống kê fixed-point và review DECIMAL thuần | Chỉ literal số không exponent, tối đa 2 MiB; quét số 0 tận cùng theo chiều ngược tuyến tính, giữ digit counts bão hòa 66/31 và negative count, không literal/min/max/hash. Project evidence kiểm tra counts/shape, precision 1–65/scale 0–30 đã kiểm chứng chung MySQL/MariaDB; scale >30 không suy hỗ trợ theo version. Dấu âm khác 0, phần nguyên vượt và mất scale được báo riêng; không tự round/chứng nhận chuyển đổi chuỗi hay đủ điều kiện ghi. Quoted numeric đi qua profile riêng v3, thiếu profile phải unknown; không đổi format backup hoặc full restore. |
| `electron/restore-selection-numeric-strings.cjs` + `restore-selection-integer.cjs` | Review chuỗi số và phạm vi integer dùng chung, thuần | Chỉ chuỗi ASCII đầy đủ ≤256 ký tự, dấu tùy chọn và fixed-point; không trim/exponent/escape/prefix parsing. Lexer chỉ giữ profile, không string gốc. Evidence v3 kiểm tra counts/shape/disjoint raw-vs-string, số nguyên dùng cùng 10-bit range mask/BigInt hữu hạn; decimal ghép digit requirements, không round. Cột khác và chuỗi lạ giữ unknown, integer không tự nhận fractional string. Chặn terminal newline bằng end check thật; v1/v2 không được suy có profile chuỗi. Giữ quotas/gates và format backup. |
| `electron/restore-selection-text.cjs` | Thống kê literal chuỗi và kiểm tra độ dài/charset thuần | Đọc vùng SQL có quota, đếm Unicode scalar/UTF8 bytes, chỉ giải mã doubled quotes; không nội dung/minmax/hash, không nới backslash grammar. Evidence v4 whitelist count/max length/ASCII/BMP/well-formed/trailing-space flags và kiểm tra subset với numeric strings. VARCHAR theo ký tự, TEXT theo bytes cho utf8mb4/utf8mb3/ascii; alias utf8/charset thiếu/khác phải unknown. CHAR giữ padding review, trailing spaces báo nguy cơ mất dữ liệu. Không tự trim/transcode/đọc dữ liệu hay gỡ gate constraints/session/execution; snapshot v7 bind charset projection, plan v16 bind report. |
| `electron/restore-selection-values.cjs` | Tổng hợp và review giá trị cơ bản thuần | Grammar INSERT chỉ bật thu thống kê khi collector yêu cầu: counts NULL/integer/other và 10-bit range mask, không raw literal/min/max/SQL. BigInt chỉ đọc tối đa 20 chữ số sau bỏ leading zeros; 10.000 vị trí toàn inventory. Project whitelist/shape/counts, đối chiếu cột nguồn có CREATE v3 và metadata đích đủ bằng chứng, mapping explicit/positional độc lập; thiếu/old/quota phải unknown. Report/evidence v4 thêm text length/charset, v1–v3 thiếu profile text phải unknown; numeric profiles v2/v3 giữ tương thích; AUTO_INCREMENT/TIMESTAMP/generated/conversion phải review, không suy đầy đủ values/constraints/server. Target projection 256 cột/bảng/2.000 cột tổng, report 100 câu/1.000 vị trí/50 findings, UI 20 câu/100 vị trí; plan v16 bind/freeze và chặn known issues nhưng không cấp quyền chạy. |
| `electron/restore-selection-session-policy.cjs` | Chính sách phiên dạng đề xuất thuần, chưa thực thi | Collector đọc FK/autocommit/SQL mode/charset bằng SELECT riêng; whitelist cờ, hash cả cờ chưa nhận diện, tối đa 4 KiB/64 cờ. Project kiểm tra fingerprint khi đủ cờ; không trả raw mode/SQL. Đề xuất giữ FK bật, utf8mb4, giữ mode đích và thêm NO_AUTO_VALUE_ON_ZERO khi context native yêu cầu; missing/unknown/weak mode/disabled checks/order/context/quota giữ findings. Tối đa 50 ánh xạ context, lifecycle/requires cố định và canExecute:false. Plan v16 freeze/bind báo cáo, snapshot v7 bind metadata; không áp dụng SET, không khẳng định nhận diện cờ là tương thích dữ liệu. Cleanup/execute/recheck/FK data validation chưa triển khai. |
| `electron/restore-selection-policy.cjs` | Chính sách xung đột dạng báo cáo thuần, chưa áp dụng | Chỉ nhận stop-on-conflict/skip-existing, validate tại IPC trước await/I/O và bind vào plan v16. Thiếu metadata/case/identity/row hoặc quá quota phải blocked; not-seen không chứng minh vắng mặt. Skip chỉ whole-table đã thấy, không thay view; schema mapping ưu tiên chặn trước skip và câu chưa phân loại giữ blocked. Dependency tới bảng skip cần đối chiếu. Giữ mọi gate nguồn/đích/context, không cấp quyền ghi/DROP hoặc xóa cảnh báo chỉ vì chọn skip. |
| `electron/restore-selection-foreign-keys.cjs` | Projection và review FK nguồn thuần | Whitelist name/pairs/schema/actions, không SQL/literal; kiểm tra CREATE v3, scope cha, policy skip/blocked, metadata cột/type/collation/SET NULL. Giữ quota 2.000 định nghĩa/10.000 cặp/100 findings, UI tối đa 100 FK. Đối chiếu full PRIMARY/UNIQUE nguồn theo thứ tự, không prefix; bổ sung quan sát khóa đích nếu thấy bảng cha, giữ block khi parent skipped; cờ invisible/ignored chỉ là metadata optimizer, không chứng nhận data/server semantics, không rewrite/sinh ALTER và không xóa gate cycle/target/context. Plan v16 bind báo cáo và vẫn canExecute:false. |
| `electron/restore-selection-indexes.cjs` | Projection chỉ mục và đối chiếu khóa nguồn thuần | Whitelist tên/loại/thứ tự cột/prefix; tối đa 128 index/16 parts mỗi bảng. Chỉ nhận full PRIMARY/UNIQUE khớp đúng thứ tự và không prefix làm bằng chứng nguồn; index thường/partial key không đủ căn cứ. Không đọc dữ liệu, sinh SQL hoặc chứng nhận quy tắc server/index ở đích. |
| `electron/restore-selection-target-indexes.cjs` | Báo cáo metadata chỉ mục đích và quan sát khóa tham chiếu thuần | Collector dò IS_VISIBLE/IGNORED trong metadata bằng SELECT/binding/quota rồi chọn đúng một identifier cố định, không đoán version hoặc tự fallback visible. Đọc STATISTICS với quota 20.000 parts, không expression/cardinality. Ghép theo index và ordinal, kiểm tra duplicate/gap/type/column/prefix/direction; giới hạn 128 index/16 parts, report 50 index/800 parts mỗi bảng và 1.000 index/4.000 parts toàn lựa chọn. Thiếu metadata/object/case/quota hoặc dạng chưa hỗ trợ phải unknown, không suy vắng mặt. Report v2 giữ enum cờ optimizer nhất quán mọi part; thiếu/khác capability hoặc report v1 cũ phải unknown. Khóa full PRIMARY/UNIQUE visible/not-ignored khớp chỉ là observed-match; Invisible/IGNORED khớp cần review, không suy ràng buộc bị tắt. Giữ kiểm tra data/server. Không gỡ gate policy/dependency; target snapshot v7 và FK report v4 bind vào plan v16, vẫn không có quyền ghi. |
| `electron/restore-selection-target-foreign-keys.cjs` | Ghép metadata FK đích thuần và báo cáo phạm vi | Collector LEFT JOIN KCU/RC bằng danh tính đầy đủ schema/bảng/constraint và bảng/schema tham chiếu, so BINARY, không inner join làm mất FK khi thiếu rule. Giữ ordinal/action/MATCH whitelist, không SQL/literal; báo cáo ghép toàn bộ trước khi lọc lựa chọn, tuple keys/Map tránh nhầm tên dotted/prototype/case. Thiếu/unknown/gap/duplicate/inconsistent/quota phải unknown; tối đa 5.000 parts đầu vào, 16 pairs/FK, report 200 definitions/1.000 pairs/50 findings và UI 100 definitions. Metadata v2/snapshot v7/plan v16; dedupe cảnh báo inbound theo constraint. Không suy dữ liệu/constraint hợp lệ, không gỡ policy/dependency/context hoặc cấp quyền thực thi. |
| `electron/restore-selection-fk-comparison.cjs` | Đối chiếu metadata FK nguồn/đích thuần | Dùng CREATE v3 đã chiếu whitelist và target FK report v1 đầy đủ; ưu tiên tên rồi ordered local columns, nhiều ứng viên phải unknown. | `electron/sql-script.cjs`, `sql-autocomplete.js`, `electron/sync-crypto.cjs` | Pure functions cho parser, gợi ý và biến đổi mã hóa | Giữ logic không phụ thuộc DOM/IPC khi có thể để kiểm thử bằng Node. |
| `electron/connection-policy.cjs` | Policy chỉ đọc thuần, dùng tại main và API database | Chặn trước khi gửi SQL/ghi dữ liệu; kiểm tra toàn bộ batch, từ chối cú pháp/hàm chưa hỗ trợ. NULL/DEFAULT là trạng thái riêng, không suy từ chuỗi người dùng nhập. |
| `electron/sync.cjs` | Bộ điều phối trạng thái đồng bộ | Một nơi điều khiển đăng nhập, retry, revision và thông báo trạng thái; tránh tự tạo luồng sync trong renderer. |
| `server/src/app.cjs` | Application factory và dependency injection | `createApp({ db, config })` nhận phụ thuộc từ ngoài; route module nhận `db`, `config`, `limiter` để test không cần mở server thật. |
| `server/src/auth.cjs`, `server/src/vault.cjs`, `server/src/errors.cjs` | Route modules và lỗi có cấu trúc | Validate tại ranh giới HTTP; trả `{ error: { code, message } }` qua `ApiError`; xử lý lỗi tập trung trong `app.cjs`. |

## Quy tắc code

- JavaScript dùng 2 dấu cách, dấu nháy đơn, dấu `;`, `const` mặc định và `let` khi cần gán lại. CommonJS (`.cjs`) cho Node/Electron; website dùng JavaScript thuần, không thêm framework hoặc build step khi chưa có nhu cầu thật.
- Hàm đặt tên theo hành động (`render...`, `load...`, `save...`, `init...`); hằng số dùng `UPPER_SNAKE_CASE`; class chỉ dùng khi có vòng đời hoặc trạng thái riêng như `DatabaseSession`.
- Tách phần thuần dữ liệu khỏi DOM, IPC, HTTP và filesystem. Không thêm logic nghiệp vụ vào callback sự kiện hoặc route dài khi có thể đặt trong hàm có tên rõ.
- Website: dùng phần tử HTML đúng ngữ nghĩa, giữ `aria-expanded`, trạng thái focus và thao tác bàn phím cho menu; dùng `textContent` cho chuỗi văn bản. Listener, timer và trạng thái của một tính năng ở cùng một hàm khởi tạo.
- CSS website: dùng biến `:root` trước khi lặp lại giá trị màu/kiểu chữ; đặt quy tắc ở nhóm component hiện hữu và kiểm tra màn hình nhỏ cùng `prefers-reduced-motion`. Tránh selector phụ thuộc sâu vào cấu trúc HTML nếu có thể dùng class rõ nghĩa.
- Renderer Electron: dữ liệu từ SQL, tệp hoặc server là không tin cậy. Escape trước khi chèn vào HTML; không đưa secret hoặc quyền truy cập Node vào renderer. Chỉ gọi API đã công bố qua `window.sqlProDesktop`.
- Main/server: xác thực và giới hạn dữ liệu ở biên; SQL value dùng placeholder, tên identifier dùng hàm quote riêng. Không log mật khẩu, token, private key, vault key hoặc plaintext vault.
- Secret local: tách đọc khóa khỏi khởi tạo; không thay khóa khi lỗi I/O, khóa hỏng hoặc đang giải mã. Chỉ tạo khóa khi chưa có secret local, dùng ghi độc quyền; lỗi giải mã phải có mã lỗi và giữ ciphertext, không trả mật khẩu rỗng.
- Tác vụ bất đồng bộ: chụp session/context và kiểm tra generation sau await trước mọi tác động. Logout/reset phải vô hiệu hóa tác vụ cũ trước khi chờ cleanup; retry/cleanup database phải đối chiếu đúng entry, không chỉ profile ID. Callback/finally cũ không được sửa trạng thái tác vụ mới.
- Ghi dòng: UPDATE phải xác nhận số dòng khớp; giữ FOUND_ROWS để phân biệt cập nhật cùng giá trị với dòng đã biến mất. Guard original-values dùng so sánh chính xác cho text, so sánh JSON document và hash đầy đủ cho binary preview; không suy dữ liệu bị cắt từ ký tự trong text. UI chỉ đổi dữ liệu/báo thành công sau xác nhận, giữ nội dung nhập khi lỗi.
- Transaction: chỉ commit/rollback transaction do thao tác tự mở. Nếu phiên đang có transaction hoặc autocommit tắt, dùng savepoint cho phạm vi thao tác và giữ chế độ của server; không tự gán autocommit=true sau cleanup.
- Admission phiên: SQL/ghi dòng/USE phải giữ lease độc quyền qua cả bước chuẩn bị có await; không chỉ dựa vào activeTask của driver. Đối chiếu fingerprint cấu hình trusted khi tái sử dụng/mở phiên; cấu hình đổi không được tự chuyển hoặc commit transaction cũ. Rollback theo sessionId/revision vẫn phải dùng được nếu profile đã bị đồng bộ xóa.
- Cache metadata dùng tuple có ranh giới rõ (JSON.stringify array), giữ exact case của identifier; không ghép dấu chấm hoặc lowercase toàn key. Invalidation phải dùng cùng dạng key.
- DELETE có original-values phải có snapshot cho từng dòng, kiểm tra engine InnoDB trước DELETE trong phạm vi transaction/metadata lock đã lấy. Không suy rollback được với MyISAM hoặc tác động trigger sang engine khác. Fixture retention dùng thời gian manifest cố định cùng clock của planner, không ghép manifest ngày thực với clock cũ.
- Đồng bộ thường và resolveConflicts dùng chung inflight; giới hạn body HTTP ngay khi đọc stream, hủy reader khi vượt quota/lỗi và decode UTF-8 sau khi ghép các chunk hữu hạn.
- Restore: preflight từ chối lệnh cấp server/global/persist và câu SET chưa hỗ trợ; schema ghi rõ phải trùng chính xác tên đích. Filter SQL không thay thế quyền database tối thiểu hoặc kiểm tra tác động gián tiếp của routine/trigger.
- Merge dữ liệu JSON: map key tùy ý dùng null prototype/Map; chỉ đọc own property và dựng property an toàn. Path phải phân biệt key có dấu chấm/backslash/key rỗng với cấu trúc lồng nhau; không đi theo prototype và không sửa input snapshot.
- Với thay đổi có ảnh hưởng đến dữ liệu, auth, đồng bộ hoặc SQL, thêm test cho hành vi và lỗi biên. Với thay đổi UI, kiểm tra tương tác bàn phím và layout trong browser/Electron ở kích thước cửa sổ nhỏ.
- Không sửa hoặc format hàng loạt mã ngoài phạm vi công việc. Giữ trạng thái sửa đổi sẵn có trong workspace; không thay đổi API hoặc định dạng lưu trữ mà thiếu migration và test.

## Kiểm tra trước khi hoàn tất

```bash
npm run check
npm run test:renderer
npm run test:website
npm --prefix server run check
npm run server:test
git diff --check
```

Website nằm trong `website/` và được Express phục vụ trực tiếp. Khi sửa nội dung/layout HTML, sửa generator rồi chạy `npm run website:build`; commit cả sáu trang HTML đã sinh. Không cần build lúc chạy server. Kiểm tra menu, copy, tìm kiếm, song ngữ, tải bộ cài, changelog và generator tự host bằng `npm run test:website`. Ảnh trong `website/assets/screenshots/` được chụp từ renderer với dữ liệu demo bằng biến `SQLPRO_SCREENSHOT_DIR` khi chạy `npm run test:renderer`. `npm run pack:linux` và `npm run pack:windows` chỉ cần chạy khi thay đổi ảnh hưởng bản đóng gói hoặc cần tạo bộ cài.
